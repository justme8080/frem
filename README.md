# Frem

Ubah screenshot tampilan webmu jadi desain baru — lalu geser elemennya,
ganti warnanya, dan ambil kodenya. Tanpa menulis kode.

**https://frem.my.id**

## Unduh

[Unduh Frem untuk Windows](https://github.com/justme8080/frem/releases/latest/download/Frem-Setup.exe)

Windows 10 & 11. Gratis.

Frem berjalan di komputermu sendiri. Pembuatan desainnya memakai
[Google Stitch](https://stitch.google.com/settings) dengan kunci API milikmu
sendiri, jadi seluruh hasilnya ada di akunmu.
